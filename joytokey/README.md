# JoyToKey profiles

Profiles for the vJoy device fed by `sbc-bridge`. Button numbers: [../docs/control-map.md](../docs/control-map.md).

Setup:
1. vJoy: device 1 → 8 axes (X Y Z Rx Ry Rz Sl0 Sl1), 80 buttons, 0 POV.
2. JoyToKey 6.2+ → Options → Stick/POV mode → "Show all axes (8 way + POV x 4)".
3. Build profile, then copy the `.cfg` from JoyToKey's profile folder into this directory.
